# InboxRove

**All your inboxes. One view.**

InboxRove is a planned client/server application with web and Android clients for monitoring multiple email accounts in one place.

**Mobile platform order:** Android first; iOS scope and timing are TBD.

## First release

- Unified recent-message metadata across connected accounts.
- Account health, background synchronization, filtering and search.
- Local new-message indicators with read-only provider behavior.
- Android monitoring through the same backend; server monitoring continues when the app is closed.

Full message reading, mailbox organization and sending are later phases. Android OS push alerts are a proposed follow-up, not a requirement for the first mobile monitor.

## Project status

Planning stage. This repository currently contains an initial README; application code, live integrations and deployments have not been created. Detailed technical choices and provider support are still under review.

The canonical PRD, detailed design and decision register are maintained under `InboxRove/` in the owner's separate Documentation repository. Those private planning artifacts are not mirrored here.
